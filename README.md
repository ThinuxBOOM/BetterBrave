# BetterBrave
This is a set of browser extensions that combines the gamer elements of Opera GX with Brave.

Instructions:
  1.Download the repository
  2.Go to Brave extensions manager and enable developer tools
  3.Click load unpacked and navigate to where the downloaded repository folder is and select the folder labelled "select"
  4.Click customize brave on the footer that shows up when you open a new tab and toggle "show footer"
  5.Enjoy!
